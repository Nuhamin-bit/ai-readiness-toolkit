# AI Readiness Toolkit

**A free 4-week program to help small teams use AI safely, confidently and well.**

Most small businesses and nonprofits have AI tools. Few have a plan to use them safely. This toolkit takes a team of 5 to 50 people from "we have AI tools" to "our team uses them safely and well" in four weeks. No AI or IT specialist is needed: one facilitator runs it.

> AI is only as safe as the people who build it and use it.

## The four abilities

The program builds four abilities, following the AI Fluency framework by Rick Dakan and Joseph Feller:

| Ability | What it means |
|---|---|
| **Description** | Explaining a task to AI clearly enough to get a useful answer |
| **Delegation** | Deciding which tasks, or steps, AI should do and which stay with a person |
| **Discernment** | Checking AI output for errors, invented facts and bias |
| **Diligence** | Using AI safely, legally and transparently |

## The 4-week plan

| Week | Focus | What happens |
|---|---|---|
| 0 | Check and choose | Everyone takes the readiness check; pick 2–3 low-risk tasks |
| 1 | Diligence | Safe-use rules come first |
| 2 | Description | Writing clear requests |
| 3 | Delegation | Breaking work into steps |
| 4 | Discernment | Catching AI mistakes; retake the check and compare |
